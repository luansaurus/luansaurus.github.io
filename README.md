# luansaurus.github.io

Portfólio pessoal de Luan Fonseca Barros, em português e inglês (botão PT/EN no topo).

Site estático: `index.html`, `style.css`, `script.js` e a pasta `img/`, publicado com GitHub Pages
(Settings > Pages > Deploy from a branch > `main` / root).

- Textos: procure os pares `<span class="pt">` e `<span class="en">` no `index.html`.
- Imagens dos projetos: ficam em `img/` (versão grande `nome.webp` e miniatura `nome-thumb.webp`).
  Cada galeria é um bloco `data-gallery`; para trocar ou acrescentar uma imagem, edite os botões `.thumb`.
